## What the clusters actually capture

The primary partition (k = 12, tfidf-char + agglomerative) scored against every metadata field. A low domain ARI next to a high language ARI means the encoder separated scripts before it separated topics; it does not mean the corpus has no topic structure.

| target | ari |
|---|---|
| domain | 0.253 |
| language | 0.175 |
| district | -0.001 |
| severity | 0.003 |

The English-only slice removes the script boundary; it is the row to quote for lexical clustering quality. The mixed-language table is dominated by the script split that only a multilingual embedding can cross, which is exactly the gap Sentence-BERT was meant to fill.

## Duplicate detection

Candidate pairs are each complaint's top-5 nearest neighbours within its district block, which is how the product behaves: a submitter sees a short list, never a full pairwise sweep. Similarity is exact sparse TF-IDF cosine. Ground truth is the injected duplicate families; the generator guarantees independent complaints never share identical text, so an exact-match hit is never a false positive. Injected near-duplicates are true paraphrases of their source (same template and slots, reworded), not a different template on the same sub-issue.

## Supervised routing baseline

The same TF-IDF features with logistic regression, trained on all 15,000 training complaints and scored on the 2,000 held-out complaints. This answers the product question "which desk does this report belong to?" and shows that the text carries domain signal even where unsupervised lexical clustering struggles.

| metric | value |
|---|---|
| accuracy | 1.000 |
| macro F1 | 1.000 |
| weighted F1 | 1.000 |

This is a synthetic ceiling, not a transfer result: every domain carries its own vocabulary by construction (a pipeline versus a culvert), so a linear model has little to confuse. It shows the pipeline can separate the domains the corpus defines; it says nothing about accuracy on real Jharkhand complaints.

## Not measured

- **Sentence-BERT.** `src/nlp/embeddings.py` implements the multilingual encoder path, but the active interpreter is CPython 3.14 with no PyTorch wheel available on this machine, and the installed 3.12 cannot start. The TF-IDF vs SBERT comparison is therefore absent rather than estimated. `models/embedding_config.json` records the blocker.
- **Inter-annotator agreement (Cohen's kappa).** The protocol calls for two annotators on a 300-complaint sample. That needs two people; it cannot be produced by the evaluator, so no kappa is reported.
- **Real-text benchmark.** The plan's CC0 Indian grievance dataset has not been downloaded into this repository. Every number here is synthetic-only and is labelled as such; no claim about real Jharkhand complaints follows from these tables.
- **District-blocked candidate generation** caps recall for duplicates filed in different districts of the same real-world problem. The sweep measures what the product does, not an unconstrained oracle.

## How to reproduce

```bash
python scripts/generate_corpus.py --records 15000 --eval-records 2000 --seed 42
python scripts/run_eval.py --sample 3000 --clusters 12 --seed 42
```
